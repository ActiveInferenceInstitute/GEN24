# Archived scripts

This directory contains historical GEN-24/FieldSHIFT-derived scripts that are not part of the active four-stage pipeline documented in [../../docs/pipeline.md](../../docs/pipeline.md).

The archived files include dissertation generation, explanation, evaluation, improvement, outlining, grant evaluation, and translation workflows. Several contain absolute paths from historical development environments and are not portable or runnable as checked in. They are retained as project history; do not use them as current setup instructions.

The active scripts are the numbered files directly under `GEN-24/`:

```text
1_generate_pro-intro.py
2_write_intro_letter.py
3_translate_intro_letter.py
4_translate_call_to_action.py
```

Path scrubbing or archival migration is deferred and tracked in the repository-level [TO-DO.md](../../TO-DO.md).
