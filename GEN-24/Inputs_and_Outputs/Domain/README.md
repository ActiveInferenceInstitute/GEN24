# `Domain/` — synthetic domain descriptions

`Synthetic_*.md` files describe the domains used as stage-1 source material
(for example astronomy, biology, blockchain, chemistry, cooking and
cognitive security). Stage 1 reads them when assembling the pro-introduction
prompt.

Add a domain as a new Markdown file here; the parent
[`README.md`](../README.md) and [`../../../docs/pipeline.md`](../../../docs/pipeline.md)
explain how the stage consumes it.
