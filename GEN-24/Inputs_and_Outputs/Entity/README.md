# `Entity/` — person worldviews

One directory per entity: `Bancroft`, `Fields`, `Friston`, `Hipolito` and
`Shyaka`. Each holds a `<Name>.py` worldview module plus `<Name>_*.md` context
documents used as stage-1 source material.

The Python file and its Markdown notes are read together; see
[`../../../docs/pipeline.md`](../../../docs/pipeline.md) for the stage that
consumes them.
